# meemcake

موقع **ميني كيك ميم** (@minicake.meem) — صفحة واحدة بالعربي، متجاوبة مع الجوال، فيها منيو تفاعلي وسلة ترسل الطلب جاهزًا على واتساب.

## التشغيل
افتح `index.html` في المتصفح. لا يحتاج أي تثبيت.

## النشر على GitHub Pages
Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `root` ← Save.
الرابط يصير: `https://<اسم-المستخدم>.github.io/meemcake/`

## التعديل
- رقم الواتساب: المتغير `WA` داخل `index.html`.
- المنتجات والأسعار: مصفوفة `products` داخل `index.html`.
- الألوان: متغيرات `:root` في أول الـ CSS.

> الأسعار والآراء ورقم الواتساب الحالية تجريبية.
